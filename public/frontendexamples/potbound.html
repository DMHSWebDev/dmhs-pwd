Why this is a Storefront site

A real cart with secure checkout.

Payments run through Stripe, a payment service used by millions of businesses. Here’s what keeps it safe:

  1. 01

    Card numbers never touch this site

    Checkout happens on Stripe’s own secure page, so the shop never sees or stores anyone’s card.

  2. 02

    Prices are checked on the server

    The cart only says what you want and how many. The server looks up the real prices, so nobody can edit the page to pay less.

  3. 03

    Stripe confirms every order

    An order only counts once Stripe sends the shop a signed message saying the payment went through.
